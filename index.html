02 / How I think

The details
are the work.

The interface is only one layer. Good engineering connects the product, the system and the people building it.

[01]

Understand before building.

Start with the people, the problem and the constraints. A useful product begins with the right questions, not a favourite framework.

[02]

Make the trade-offs clear.

Keep architecture understandable. Choose what the product needs, document decisions and leave room for the next engineer.

[03]

Own the whole delivery.

Code reviews, mentoring and release discipline are part of the product. The work isn't finished at the pull request.

Tools, chosen for the job.

Build the product
Laravel / PHP / React / React Native / WordPress
Connect the systems
REST APIs / MySQL / Node.js / Stripe / PayPal
Deliver with confidence
AWS / Docker / Git / CI/CD / Code reviews
