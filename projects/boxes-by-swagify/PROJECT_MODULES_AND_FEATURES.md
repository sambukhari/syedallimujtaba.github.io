# Project Modules & Features — Boxes by Swagify (storefront + backend)
**Repository:** https://github.com/ashiq/BoxesbySwagify
**Companion repository:** https://github.com/ashiq/BoxesbySwagifyBackend
**Reviewed:** `master` (2026-10-24)

## Project feature list
- Storefront: Build-a-box, prebuilt boxes and product selection
- Storefront: Shopping cart, order information and order details
- Storefront: Sign-in, registration, password reset and customer dashboard
- Storefront: FAQs, contact, services and informational pages
- Backend API: Product, box, category and filtered catalog APIs
- Backend API: Cart updates, box customization and logo pricing
- Backend API: Customer registration, login, logout and password recovery
- Backend API: Order creation, customer dashboard, FAQs and contact endpoints

## Requested modules (short details)
1. **User Management:** Customer sign-in, registration, reset and dashboard screens in Vue; Laravel register, login, logout and password-recovery endpoints.
2. **API for App:** Axios frontend integration and Laravel API routes for auth, boxes, products, carts and orders; real request/response compatibility was not runtime-verified.
3. **KYC:** Not evidenced in either reviewed repository.
4. **HR Management System:** Not evidenced; a careers page is not an HR system.
