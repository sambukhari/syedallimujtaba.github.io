# Project Modules and Features - Priority Fix

## Existing App Features
- **Tenant Access:** Sign-up, login, terms acceptance, and profile editing.
- **Repair Requests:** Report issues, attach videos, and view details.
- **Repair Tracking:** View status, contractor/visit information, and confirm completion.
- **Notifications:** Push notification support.

## Requested Modules (Proposed Scope)
1. **User Management:** Users, roles, permissions, and account status.
2. **API for App:** Secure endpoints, authentication, validation, and responses.
3. **KYC:** Identity documents, verification, and approval status.
4. **HR Management System:** Employees, attendance, leave, and payroll.

**Note:** Proposed modules are a feature list, not a claim that they are built. No repository branch is changed.
