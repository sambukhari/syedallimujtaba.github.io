# Priority Fix portfolio case study

This directory contains a source-faithful interpretation of the uploaded short Markdown brief.

- `PROJECT_MODULES_AND_FEATURES.md` is the original feature list.
- `project.json` is the portfolio presentation manifest.
- `index.html` is generated by the shared build command.
- `assets/` holds architectural concept artwork and can hold future authentic screenshots/videos.

## Important distinctions
**Existing features listed:** Tenant Access, Repair Requests, Repair Tracking, Notifications.
**Proposed (NOT IMPLEMENTED in this evidence):** User Management, API for App, KYC, HR Management System.

The brief supplies no repository, language/framework, screenshots, delivery dates, personal contribution notes, contract details, demo or production outcomes. None are invented in this page. "Existing" means "listed in the user's document", not independently code-audited.

Conceptual SVGs in `assets/` are **not application screenshots**.

To add media later, place accessible files in `assets/` and add `{ "src": "assets/image.webp", "kind": "screenshot", "title": "...", "caption": "...", "alt": "..." }` to `project.json.media`, then run `npm run build && npm run check`. Use `kind: "video"` with `.mp4` or `.webm` and consent-cleared material. Future evidence can establish exact stack, ownership, workflows and outcomes.
